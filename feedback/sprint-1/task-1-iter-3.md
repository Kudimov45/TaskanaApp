❗**Семантика:**

**content:**
семантически неверная разметка компонента:

```jsx
<>
     <main>
          <section className={style.content}>
                  <NavBar/>
                  <IncomingTasks/>
                  <SideBar/>
          </section>
      </main>
</>    
```
по спецификации HTML тег `<main>` должен содержать основной уникальный контент страницы и не должен включать повторяющиеся элементы интерфейса (`<nav>`, `<aside>`);
использование здесь фрагмента <>`</>` излишне, компонент и так имеет общий корневой элемент;

**tasks:** использование тега `<article>` кажется спорным с точки зрения семантики, логичнее `<main>` или `<section>`;

⬆ **Cкролл:**

- при появлении горизонтального скролла при ширине экрана менее 1280px одновременно появляется общий вертикальный скролл - по макету его быть не должно;
- **sideBar:** помимо вертикального скролла в этой секции появляется горизонтальный - противоречит ТЗ (см скриншот);
❗обрати внимание, что при переполнении контента в этой секции при скролле первый компонент Statistic недоступен (см скриншот): при использование свойства {justify-content: center} в контейнере одновременно с {flex-direction: column} и {overflow-y: auto} браузер пытается центрировать ВСЁ содержимое по вертикали, а не только один элемент, но когда элементов становится больше, чем высота контейнера центр «уезжает» верхняя часть выходит за пределы и скролл не даёт добраться до самого верха 👉 именно поэтому у тебя первый Statistic «обрезается». В своем проекте для центрирования контента я использую обертку
```css

     .center-wrapper {
        flex: 1;
        display: flex;
        align-items: center;
        justify-content: center;
     }

     ```

- скролл центральной части должен захватывать и область заголовка 'Входящие' (см. макет);
